## 一、这个项目是什么

**LexSynergy Legal QA System** —— 一个面向**法律合规场景**的垂直领域多 Agent 专家问答系统。
它是用户**要写进简历的项目**，因此衡量标准不只是"能跑"，而是：

1. 有**可复现的量化数字**支撑核心主张；
2. 技术选择**经得起追问**（为什么这么做、不这么做会怎样）；
3. 诚实标注边界（做不到什么、哪条结论其实站不住）。

## 二、20 分钟上手

```bash
cd "E:/project/LexSynergy Legal QA System"

# 环境（Windows + Git Bash；这些线程变量是必须的，见 06）
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1

# 1) 离线单测：应 245 passed / 2 skipped，零网络
.venv/Scripts/python.exe -m pytest -o addopts="" -q

# 2) 校验能力：应 8/8 检出、0 误报
.venv/Scripts/python.exe -m eval.seeded_defect

# 3) 金额金标：应 30/30 一致
.venv/Scripts/python.exe -m scripts.check_calc_gold

# 4) 跑一个问题（首次会预热检索模型 ~16-20s，属正常）
#    注意：经济补偿需要"入职日+离职日+月薪"三个槽位，缺一个系统会先追问（这是设计行为）
.venv/Scripts/python.exe -m app.runtime ask \
  "公司裁员，我 2021 年 3 月 1 日入职，月薪 12000，能拿多少经济补偿？" \
  --facts '{"monthly_wage":12000,"start_date":"2021-03-01","end_date":"2026-10-20"}'
# 期望：mode=full、五道闸通过、结论 72000.00 元、约 2~4s（预热之后）

# 5) 看协作时间线（前端）
.venv/Scripts/python.exe -m uvicorn app.api.main:app --host 127.0.0.1 --port 8201
# 浏览器打开 http://127.0.0.1:8201
```
