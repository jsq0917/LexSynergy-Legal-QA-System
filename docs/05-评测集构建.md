# 05 · 评测集是怎么来的（以及它的偏差）

> **后续**：100 条集已在 2026-10-28 扩到 **130 条**（多跳 12→37、复杂 8→13）。
> 多跳/复杂题的构建方法、人工剔除记录与偏差另见 `docs/07-多跳评测集.md`；
> 本文件描述的是前 100 条（尤其是 60 条生成题）的口径，两者不可混用。

之前的 40 条样本只够看趋势：**40 题的 95% 置信区间约 ±12pt**，
"引用命中 +3pt"这种结论落在噪声里也说不清。这份文档记录扩充到 100 条的完整方法，
包括**哪些地方可能有偏**——这比"我们扩样了"重要。

## 1. 为什么不能手写

60 条带金标条号的题，手写等于 60 次"我记得是第四十七条"。错一条，指标就被污染，
而且**错了也看不出来**（没有外部信号能发现）。

所以金标直接从语料派生：**给一条法条，让模型写一个当事人会问的问题，答案就是这条法条本身。**
金标的正确性由构造方式保证，不依赖记忆。

## 2. 生成流程（`eval/gen_qa_set.py`）

```
抽样条文（分层 + 固定种子）
   ↓
LLM 写口语问题（禁止条号/法名，禁止照抄原文）
   ↓
程序化过滤：题面与原文的字符二元组重合率 > 0.45 直接丢弃
   ↓
第二次 LLM 调用：这条法条能否直接回答该问题？（判否即丢弃）
   ↓
入库（eval/generated/qa_candidates.jsonl）
```

两个过滤各挡一类偏差：

| 偏差 | 为什么致命 | 挡法 |
|---|---|---|
| **题面泄漏原文** | 检索会退化成词组匹配，召回虚高，且四个配置一起虚高——看起来"都很好" | 重合率阈值 0.45，实测通过项的**中位 0.08、最大 0.36** |
| **问题超出一条法条** | 金标本身就是错的，等于给系统判错 | 第二次调用专判"能否由该条回答" |

抽样分层：劳动合同法 22 条、劳动法 10 条、民法典 28 条（民法典原本只有 6 题，
是本项目最弱的法域，这次补到 33 题）。

## 4. 三个必须写出来的偏差

**① 题型分布被拉向单跳。** 生成的 60 题全是单跳，所以 100 条集的 R@5 会**高于** 40 条集
（简单题占比从 37.5% 涨到 75%）。**两套数字不可混用**：报告里 40 条的旧数字保留，
100 条的新数字单独标注，横向只跟同集合比。

**② 生成题比真题"好问"。** 模型知道答案在哪条，写出的问题天然贴合该条的语义中心；
真实用户的问法更偏、更碎。所以**生成题的绝对分数偏乐观**，但四个配置吃的是同一批题，
**差异（配对比较）仍然有效**——这是配对设计的价值。

**③ 金标只经过机器校验，没有人工逐条复核。** 60 条里 54 条一次通过、6 条被质检判否。
判否的典型理由是"该条只规定原则，具体条件在别的条"——这类被正确挡掉了，但**漏网仍有可能**。

对应的自查手段：跑完后统计"四个配置都没检索到金标"的题，逐条看是不是题本身有问题。
这类题**不删**——删掉失败题等于挑选样本，会让指标虚高。

## 5. 统计方法：配对 bootstrap（`eval/compare_stats.py`）

四个配置跑的是**同一批题**，逐题结果高度相关，把两组当独立样本算区间会低估精度。
所以：

* 单配置区间：对题目重采样 4,000 次取 2.5%/97.5% 分位；
* **差异区间：对"逐题差值"重采样**（paired bootstrap），保持配对结构；
* 区间不含 0 才标 `*`（这里叫"可区分"，不叫"显著"——样本量和分布假设都撑不起 p 值语言）。

```bash
python -m eval.compare_stats                # 100 条集
python -m eval.compare_stats --samples eval/qa_test_cases.jsonl   # 旧 40 条
```

## 6. 复现

```bash
python -m eval.gen_qa_set --concurrency 4      # 60 条约 40 秒（含 120 次调用）
python -m eval.build_set                       # 合成 100 条
python -m eval.compare_agents --faithfulness   # 四档全量，约 15 分钟
python -m eval.compare_stats                  # 带区间的表
```

种子固定（`--seed 20261028`），抽样可复现；LLM 生成的题面会有措辞波动，
但金标（法名 + 条号）由抽样决定，**不受措辞影响**。
